# Как менять товары

1. Запустите сайт и откройте http://127.0.0.1:5173/admin.
2. Войдите с паролем владельца.
3. Найдите товар по названию и выберите его.
4. Измените цену, название, описание или категорию. Для новой фотографии выберите JPG, PNG или WebP на компьютере (до 8 МБ).
5. Нажмите «Сохранить изменения». Загрузка фотографии сама по себе ещё не сохраняет карточку.

Для упаковок можно менять цену каждого варианта отдельно. Чтобы убрать товар из продажи без удаления, выключите его наличие и сохраните. Изменения сохраняются в базе и не пропадают после перезапуска.

## Первый вход

В папке проекта выполните `npm.cmd run admin:link` и откройте выданную личную ссылку. Придумайте пароль минимум из 12 символов, повторите его и подтвердите. Ссылку и пароль не отправляйте другим людям.

## Сохранность

Проект: `C:\Users\User\Documents\GitHub\RE`. Данные и загруженные фото находятся в `storage/orders.sqlite` (либо по адресу ORDERS_DB_PATH). Не удаляйте папку storage. Перед копированием базы остановите сайт и копируйте всю папку storage. При размещении на сервере нужно перенести базу и подключить постоянный диск.
